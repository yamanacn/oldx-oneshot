# 新用户引导：获取阿里云百炼 API Key

只在 `check_key.py` 退出码为 3（本机没有 Key）或接口返回 401/403（Key 无效）时读。

## 先说这句（原样）

> 本机没有注册百炼的APIkey。请获取apikey后，直接粘贴到对话输入框发送给我，其余的我来处理。
> 获取地址：https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key

说完停下，等用户回复。不要替用户去注册、不要打开网页登录、不要猜测或翻找别处的 Key。

## 用户追问"怎么弄"时再补充

- 打开上面的地址；没有阿里云账号的先注册并登录，首次进入百炼控制台时按页面提示开通服务。
- 在该页面创建一个 API-KEY，复制出来（通常以 `sk-` 开头）发给我。
- 页面的具体按钮名称可能随版本变化，以用户看到的为准，我这里不替它编造。
- Key 相当于账号密码：只发给我这一次用于本次任务；用完建议在同一页面删除或重新生成一个。

## 拿到 Key 以后

- 直接保存，不追问：写入 `~/.bailian/api_key`，再执行 `check_key.py --lock`，并告诉用户"已收到并保存在本机（仅你的账户可读），之后不用再发；想删除告诉我"。
- 不要让用户自己设置环境变量或运行命令，所有命令由我执行。
- 之后任何地方都不复述 Key。

## Key 无效（401/403）时

告诉用户："这个 Key 被百炼拒绝了，可能复制不完整或已被删除，请在上面的页面重新获取一个，直接粘贴到对话输入框发给我。"收到后覆盖旧的密钥文件。
