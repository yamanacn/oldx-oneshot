# 用包装遮盖人物视频里的异常

人物视频（尤其是数字人生成的）某几秒出了问题——灯光变色、背景多出东西、嘴不动、手形别扭——而用户不想重新生成时读。做法是在异常出现前让人物缩到右下角的小窗（或暂时隐藏），主画面演这几句话对应的内容，异常过后再回来。重新生成要花钱和时间，而且同样的输入常常得到同样的问题；遮盖只需要本地合成。

## 什么时候用，什么时候不用

用：异常只占几秒到十几秒，且那几句话本来就适合让画面来讲。

不用，改为重跑问题段：
- 异常在片头 3 秒内——开场要靠人物的脸建立交流。
- 异常落在用户专门设计的表演上（指定的手势、表情、动作）。用 `--protect 起-止` 把这些时间段保护起来。
- 遮盖总时长会超过全片约 40%——成片会变成幻灯片。`cover_plan.py` 会给出 `recommend: rerun`。
- 声音本身有问题——遮盖只处理画面。

## 流程

1. **拿到异常时间段。** 数字人技能的 `qa_video.py` 会写出 `avatar/anomalies.json`（逐秒和输入图片比背景色相与彩度，加上“说话时嘴不动”的区间）。脚本发现不了的问题（背景里多出物体、手形错误）靠看抽帧，手工加进这个文件：`{"start", "end", "type", "cover", "detail"}`。
2. **选遮盖方式**（写在每条异常的 `cover` 字段）：

   | 异常 | `cover` | 理由 |
   |---|---|---|
   | 背景局部变化、整幅轻微偏色 | `content_pip`（缩到右下角） | 小窗只取头肩，背景大部分被裁掉，偏色缩小后不显眼 |
   | 人物本身出错（嘴不动、脸或手变形），或背景整个变了（变黑、换了场景） | `content_full`（隐藏人物） | 小窗里仍看得出来，这几秒完全隐藏人物，声音照常 |

3. **规划区间**：`python scripts/packaging/cover_plan.py plan --anomalies … --words … --out covers.json`。起点至少比异常早 1.5 秒并往前对齐到句子开头（人物要在异常出现前缩完，而且切换落在语义上才不突兀），终点对齐到异常结束后的下一句开头；太近的区间合并，太短的延长。
4. **设计这几秒的主画面**：读 `covers.json` 里每个区间的 `sentences`，按这条片子的设计给这几句话做画面。内容要和正在说的话有关——遮盖的目的是不让观众注意到异常，放一张无关的图反而让人出戏。（用备用合成器时没法做图形动画，才退回到要点卡：存成 `cards.json`，格式见 `cover_plan.py` 文件头。）
5. **合成**：把规划出的遮盖区间写进 `Film.tsx` 里人物层的 `runs`（缩到右下角）或 `hide`（隐藏；人物在角上时会滑出画面再滑回来，不是原地消失），照常渲染，再跑 `av_check.py`。能挪的话，把隐藏的起止挪到最近的换场处。小窗的取景（头肩在画面里的位置）先看一眼人物截帧再填。没有 Node、用备用合成器时：`cover_plan.py spec …` → `pip_render.py` → `av_check.py`。
6. **看结果**：打开 `av_check.py` 导出的进场、退场过渡图，确认人物开始缩小时画面还正常、放大回来时已经恢复；再在遮盖区间中段取一两张静帧，看小窗里的偏色是否可以接受。仍然明显时把那条异常的 `cover` 改成 `content_full` 重新规划。

## 和常规包装一起做

遮盖区间就是人物缩小或隐藏的区间，只是它的位置由异常决定而不是由内容决定。片子本来就要做包装时，先按设计排好人物缩小的区间，再把异常区间并进去：已经落在缩小区间里的轻微异常不用另外处理；没盖住的，优先把相邻的内容段延长过去。

## 交付时说明

列出遮盖了哪几段（起止时间、原因、用的方式）和没能遮盖、建议重跑的段。小窗里仍可能看出轻微偏色，这一点如实告诉用户，由用户播放后决定是否接受。
